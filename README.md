# C 盘清理工具

Windows 下的图形化 C 盘清理工具，先扫描、再勾选、后清理。基于 Python + tkinter，无需安装任何第三方库。

## 两种运行方式

**方式一：直接用 exe（目标电脑不需要 Python）**

把 `dist\C盘清理工具.exe` 拷到目标电脑，双击运行即可。首次运行 Windows SmartScreen 可能提示"未知发布者"，点"更多信息 → 仍要运行"。日志写在 exe 同目录的 `logs\` 下。

**方式二：源码运行（需要 Python 3.10+）**

把整个文件夹拷过去，双击 `启动.bat`。程序会请求管理员权限，随后打开窗口。

## 使用方法

界面参考金山毒霸磁盘管理，左侧为功能导航：

1. **C盘瘦身**：自动统计各项占用，勾选后点「一键瘦身」。
2. **碎片清理**：选择磁盘后分析并优化（碎片率/碎片空间/可用空间）。
3. **隐私清理**：浏览器历史、Cookie、最近记录，以及注册表使用痕迹（文件访问、系统痕迹、搜索记录、USB 记录）。
4. **大文件专清**：默认扫描**全部磁盘**的大文件（>100MB），可切换单个磁盘。
5. **重复文件专清**：默认**全部磁盘**范围按内容查重，可切换「用户目录」或单个磁盘。
6. **微信专清 / QQ专清**：按图片/视频/语音/文件/缓存/日志分类清理，只删媒体文件，不动聊天数据库。
7. **文件粉碎**：彻底覆盖删除文件或文件夹。
8. **软件搬家**：在「C盘瘦身」页的「软件搬家」标签，把大目录搬到其他盘并建立联接。

## 规则库与云端更新

- 内置规则在 `rules.json`，可自行扩展；已覆盖常见软件缓存（钉钉、企业微信、飞书、迅雷、网易云音乐、QQ音乐、爱奇艺、腾讯视频、B站、剪映、搜狗输入法、Office、Adobe、Steam、Teams 等）。
- **云端更新**：在 `rules_update.json` 里填写远程 `rules.json` 的地址，点界面右上角「规则更新」即可拉取并合并新规则（按 key 去重，重启工具后生效）。

## 迁移功能（搬到其他盘）

有些目录不能删（聊天记录、项目文件、插件等），但可以搬到空间更大的盘，同时保持原路径可用。

1. 切到「迁移」页，工具会列出常见的大目录并显示大小和状态。
2. 选中一个「可迁移」目录，选择目标盘和文件夹（默认 `<盘符>:\MovedData`）。
3. 点 **迁移选中目录**，确认后执行。工具会：
   - 先把数据完整复制到目标盘；
   - 校验复制完整后删除原目录；
   - 在原位置建立目录联接（junction），程序照常按原路径访问。
4. 想还原时，选中「已是联接」的目录，点 **撤销迁移**，数据会搬回原位置。

**安全设计**：先复制后删除，复制不完整或文件被占用时自动回滚，不会丢数据；建立联接后会实际进入子目录校验，若该位置不支持跨卷联接（例如部分环境下的 `AppData`）会自动还原；不迁移系统目录、用户配置根目录和整个磁盘；联接目录不会被清理功能跟随删除。

## 规则外置化（rules.json）

除内置清理项外，同目录的 `rules.json` 可以追加清理规则，改规则不用改代码。字段说明：

- `paths`：文件或目录路径，支持 `%环境变量%` 和通配符 `*`
- `glob_dirs`：只匹配目录
- `patterns`：文件名匹配（默认 `*`）
- `tier`：`conservative` / `standard` / `deep`
- `warning`：风险提示，清理确认时显示
- `kind`：`files` / `command`（`command` 配合 `command` 字段执行外部命令，如碎片整理）

内置通过 `rules.json` 增加的项包括：微信/QQ 专清缓存、浏览器隐私痕迹、最近使用记录、系统瘦身（日文/韩文输入法）、磁盘碎片整理。

## 重复文件与工具

- **重复文件**：按大小分组 → 采样哈希 → 全文件哈希，结果按重复组展示；「智能选择」每组保留一份、选中其余，确认后删除。默认扫描用户目录，可切换到其他盘或添加文件夹。扫描优先使用 MFT 快速枚举，异常时自动回退并行/串行扫描。
- **工具**：磁盘碎片整理（`defrag C: /O`，SSD 仅 TRIM）、文件粉碎（覆盖写后删除，不可恢复）、清理历史（时间/释放/清理项数，双击打开对应日志）、打开日志目录。

## 快速扫描（NTFS MFT）

- 整盘或大文件扫描时，调用随工具打包的 `mftreader.exe`（Rust 编写）**直接解析 NTFS 的 $MFT**，一次性顺序读出全盘文件记录，C 盘约 49 万文件 ~10 秒枚举完，比递归扫描快一个数量级。
- 小目录扫描使用多线程并行遍历；MFT 不可用时（非 NTFS、无管理员权限、卷被占用）自动回退到并行/串行扫描。
- 读取卷需要管理员权限；MFT 按记录去重，硬链接不会重复计数。
- **索引缓存**：首次扫描后把全盘文件列表缓存到 `%LOCALAPPDATA%\C盘清理工具\mftcache`（每个卷一个约 60 MB 的文件）。之后用 USN 日志的 `NextUsn` 判断文件系统是否变化：没变化直接读缓存，10 分钟内也复用缓存。实测首次约 10 秒、重复扫描约 0.3 秒。工具页的「强制刷新索引」可清除缓存、下次重新读取 MFT。
- 重新编译：`rustc -O -C panic=abort mftreader.rs -o mftreader.exe`。

## 安全设计

- **只删白名单内的路径**：所有可清理位置都在 `categories.py` 中显式列出，删除前还会做路径归属校验。
- **不跟随链接**：跳过 junction / 符号链接，避免顺着链接删到其他位置。
- **跳过占用文件**：正在被程序使用的文件会自动跳过，不会强制结束进程。
- **默认先扫描**：没扫描过不允许直接清理。
- **深度操作二次确认**：DISM、休眠、Windows.old 会在确认框里单独列出后果。
- **全程日志**：每次清理写入 `logs/`，记录时间、删除数量、释放大小和错误。

## 不会碰的东西

`C:\Windows\System32`、`Program Files`、用户文档/桌面/图片、已安装程序、注册表，均不在任何清理范围内。

## 注意事项

- 被程序或服务占用的文件无法立即删除，工具会登记到系统，下次重启时自动删除；重启后再扫描就能看到剩余减少。传递优化缓存（约 1 GB）通常属于这种情况。
- 清理浏览器缓存后，部分网站首次打开会稍慢，属于正常现象。
- 「开发工具缓存」清空后，下次构建会重新下载依赖。
- 「系统事件日志」清空后历史诊断记录不可恢复。
- 「搜索索引」删除后系统会在后台重建，期间搜索会变慢，通常几分钟到几十分钟。
- 深度档的 DISM 组件清理可能需要 5-20 分钟，期间请勿关闭窗口。

## 重新打包

修改源码后，在项目目录执行：

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name "C盘清理工具" main.py
```

生成的 exe 在 `dist\` 下。
