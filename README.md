# C 盘清理工具

Windows 下的图形化 C 盘清理工具，先扫描、再勾选、后清理。基于 Python + tkinter，无需安装任何第三方库。

## 两种运行方式

**方式一：直接用 exe（目标电脑不需要 Python）**

把 `dist\C盘清理工具.exe` 拷到目标电脑，双击运行即可。首次运行 Windows SmartScreen 可能提示"未知发布者"，点"更多信息 → 仍要运行"。日志写在 exe 同目录的 `logs\` 下。

**方式二：源码运行（需要 Python 3.10+）**

把整个文件夹拷过去，双击 `启动.bat`。程序会请求管理员权限，随后打开窗口。

## 使用方法

窗口标题是「磁盘清理助手」。左侧为功能导航，各项会显示已扫描到的体积或条数：

1. **C盘瘦身**：自动统计各项占用，勾选后点「一键瘦身」。
2. **碎片清理**：选择磁盘后分析并优化（碎片率/碎片空间/可用空间）。
3. **隐私清理**：浏览器历史、Cookie、最近记录，以及注册表使用痕迹（文件访问、系统痕迹、搜索记录、USB 记录）。
4. **大文件专清**：默认扫描**全部磁盘**的大文件（>100MB），可按视频、音乐、文档、图片、压缩包、其他筛选，并按大小或修改时间排序。删除前先预览，默认移入回收站。
5. **重复文件专清**：按内容查重，结果按组展示。每组自动保留一份，即使全选也不会把最后一份删掉。删除前预览，默认移入回收站。
6. **微信专清 / QQ专清**：按月列出图片、视频、语音、接收文件、缓存和日志。接收文件再按办公文档、视频、图片、音乐、压缩包、其他分类。新版微信里位于媒体目录的 `.dat` 和无扩展名文件也会识别；数据库和配置不会动。删除前预览，默认移入回收站。
7. **文件粉碎**：先放入待粉碎列表（可拖入文件），确认后才覆盖删除。系统目录、盘符根和关键系统文件会被拒绝。粉碎历史可回看。
8. **软件搬家**：在「C盘瘦身」页的「软件搬家」标签。候选来自卸载注册表，不会列出文档、桌面、下载。「大文件搬家」会把选中的大文件复制到其他盘，校验后再在原位置建立链接，失败会还原。

## 规则库与云端更新

- 内置规则在 `rules.json`，可自行扩展；共约 100 条，覆盖浏览器（Chrome/Edge/Firefox/Brave/Opera/QQ浏览器等）、通讯会议（钉钉、企业微信、飞书、Telegram、Discord、Slack）、影音（网易云音乐、QQ音乐、爱奇艺、腾讯视频、B站、剪映）、开发工具（VS Code、JetBrains、Android Studio、npm/pip/uv、Go 构建缓存）、游戏平台（Steam、Epic、Battle.net）与常用国产软件缓存。Gradle/Conda 的大缓存是代码内置项（深度档）。注意：`rules.json` 条目都按不可信规则执行，目标必须落在临时目录或路径段名为缓存/日志的目录内，否则会被安全检查跳过。
- **云端更新**：在 `rules_update.json` 里只填写 https 地址。远程规则不能带命令，也不能指向文档、桌面或下载，只能落在临时目录或缓存目录。清理执行时会再检查一次路径。本地自带的碎片整理命令不会被远程规则覆盖。

## 迁移功能（搬到其他盘）

有些目录不能删（聊天记录、项目文件、插件等），但可以搬到空间更大的盘，同时保持原路径可用。

1. 切到「迁移」页，工具会列出常见的大目录并显示大小和状态。
2. 选中一个「可迁移」目录，选择目标盘和文件夹（默认 `<盘符>:\MovedData`）。
3. 点 **迁移选中目录**，确认后执行。工具会：
   - 先把数据完整复制到目标盘；
   - 校验复制完整后删除原目录；
   - 在原位置建立目录联接（junction），程序照常按原路径访问。
4. 想还原时，选中「已是联接」的目录，点 **撤销迁移**，数据会搬回原位置。

**安全设计**：先复制后删除，复制不完整或文件被占用时自动回滚，不会丢数据；建立联接后会实际进入子目录校验，若该位置不支持跨卷联接（例如部分环境下的 `AppData`）会自动还原；不迁移系统目录、用户配置根目录和整个磁盘；联接目录不会被清理功能跟随删除。

## 规则外置化（rules.json）

除内置清理项外，同目录的 `rules.json` 可以追加清理规则，改规则不用改代码。字段说明：

- `paths`：文件或目录路径，支持 `%环境变量%` 和通配符 `*`
- `glob_dirs`：只匹配目录
- `patterns`：文件名匹配（默认 `*`）
- `tier`：`conservative` / `standard` / `deep`
- `warning`：风险提示，清理确认时显示
- `kind`：`files` / `command`（`command` 只允许写在本机 `rules.json` 里，例如碎片整理。远程更新不能带入命令）
- `exclude`：排除的文件名通配（如 `*.docx`），命中 patterns 但被排除的文件不动
- `min_age_minutes`：只清理 N 分钟前修改的文件（内置用户/系统临时文件默认 1440）
- `process_absent`：列出的进程（如 `WeChat.exe`）运行中时整项跳过（仅本机规则）
- `detect`：探测路径全部存在时才启用该规则（仅本机规则）
- `os_min` / `os_max`：适用的系统版本范围，如 `"os_min": "10.0"`（仅本机规则）

远程更新只允许下发 `exclude` 与 `min_age_minutes` 这类只收紧不放宽的字段；
恢复目录、系统还原卷信息与 `usmt.ppkg` 属于永不清理硬名单，任何规则都不能碰。
注册表痕迹清理前会自动把目标键导出到 `logs\backups` 下的 .reg 文件，导出失败则跳过不删。

内置通过 `rules.json` 增加的项包括：微信/QQ 专清缓存、浏览器隐私痕迹、最近使用记录、系统瘦身（日文/韩文输入法）、磁盘碎片整理。

## 重复文件与工具

- **重复文件**：按大小分组 → 采样哈希 → 全文件哈希。打开结果时每组保留修改时间最新的一份，其余默认勾选。确认时仍会再检查一次，保证每组至少留一份，然后移入回收站。
- **工具**：磁盘碎片整理会先读取 `defrag /A` 的碎片率、碎片量和碎片数，分布图按这个比例绘制，读不到分析结果时不显示假格子。文件粉碎前进入待处理列表。清理历史在侧栏「清理历史」，双击可打开对应日志。

## 快速扫描（NTFS MFT）

- 整盘或大文件扫描时，调用随工具打包的 `mftreader.exe`（Rust 编写）**直接解析 NTFS 的 $MFT**，一次性顺序读出全盘文件记录，C 盘约 49 万文件 ~10 秒枚举完，比递归扫描快一个数量级。
- 小目录扫描使用多线程并行遍历；MFT 不可用时（非 NTFS、无管理员权限、卷被占用）自动回退到并行/串行扫描。
- 读取卷需要管理员权限；MFT 按记录去重，硬链接不会重复计数。
- **索引缓存**：首次扫描后把全盘文件列表缓存到 `%LOCALAPPDATA%\C盘清理工具\mftcache`（每个卷一个约 60 MB 的文件）。之后用 USN 日志的 `NextUsn` 判断文件系统是否变化：没变化直接读缓存，10 分钟内也复用缓存。实测首次约 10 秒、重复扫描约 0.3 秒。工具页的「强制刷新索引」可清除缓存、下次重新读取 MFT。
- 重新编译：`rustc -O -C panic=abort mftreader.rs -o mftreader.exe`。

## 安全设计

- **只删白名单内的路径**：所有可清理位置都在 `categories.py` 中显式列出，删除前还会做路径归属校验。
- **不跟随链接**：跳过 junction / 符号链接，避免顺着链接删到其他位置。
- **跳过占用文件**：正在被程序使用的文件会自动跳过，不会强制结束进程。
- **默认先扫描**：C 盘瘦身在扫描完成前不能清理。
- **大文件、重复文件、微信/QQ 先预览**：确认框会列出将要处理的路径，默认送进回收站，不直接永久删除。粉碎除外。
- **不删除浏览器密码库**：Chrome / Edge / 夸克 / Firefox 的 `Login Data`、`logins.json`、`key4.db` 即使出现在规则里也会跳过。
- **深度操作二次确认**：DISM、休眠、Windows.old 会在确认框里单独列出后果。
- **全程日志**：每次清理写入 `logs/`，记录时间、清理项和释放大小。侧栏「清理历史」可回看，双击打开日志。

## 不会碰的东西

`C:\Windows\System32`、`Program Files`、用户文档/桌面/图片、已安装程序、注册表，均不在任何清理范围内。

## 注意事项

- 被程序或服务占用的文件无法立即删除，工具会登记到系统，下次重启时自动删除；重启后再扫描就能看到剩余减少。传递优化缓存（约 1 GB）通常属于这种情况。
- 清理浏览器缓存后，部分网站首次打开会稍慢，属于正常现象。
- 「开发工具缓存」清空后，下次构建会重新下载依赖。
- 「系统事件日志」清空后历史诊断记录不可恢复。
- 「搜索索引」删除后系统会在后台重建，期间搜索会变慢，通常几分钟到几十分钟。
- 深度档的 DISM 组件清理可能需要 5-20 分钟，期间请勿关闭窗口。

## 重新打包

修改源码后，在项目目录执行：

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name "C盘清理工具" main.py
```

生成的 exe 在 `dist\` 下。
