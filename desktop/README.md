# C 盘清理工具（Rust + Tauri）

Windows 下的图形化 C 盘清理工具。Rust 负责扫描、删除、粉碎和隐私清理，
界面是 Vue 3 + Vite + TypeScript，源码在仓库根的 `web/`，构建产物在编译期嵌入 exe。

## 目录

```
desktop/
  Cargo.toml           Rust 依赖
  build.rs             tauri-build 入口
  tauri.conf.json      窗口、打包、资源（rules.json / rules_update.json）
  capabilities/        窗口权限
  src/main.rs          后端命令：磁盘信息、清理项统计、大文件、重复文件
web/                   前端（Vue 3 + Vite + TypeScript，构建产物 dist 嵌入 exe）
  src/pages/           9 个页面
  src/stores/          各页面状态与 Tauri 调用
```

## 已迁移

- 窗口外壳：侧栏 8 项、页面切换、窗口最小化/最大化/关闭
- 首页「C盘瘦身」：C 盘占用条 + 按 `rules.json` 统计的清理项卡片（推荐/谨慎分组、勾选、合计），勾选后可直接清理
- 碎片清理：调用 `defrag.exe /A /V` 分析（中英文输出都能解析）、`/O` 优化，识别固态盘（走 TRIM），按碎片率画分布格
- 隐私清理：浏览器历史 / Cookie / 下载记录（Chromium 系 + Firefox，SQL 在副本上执行后写回）、最近敏感文件、最近文档、UserAssist、媒体播放记录；注册表删除前用 `reg.exe` 导出备份
- 大文件专清：进程内直读 NTFS `$MFT` 枚举（`mft.rs`），按类型页签筛选、勾选、排序，清理时移到回收站
- 重复文件专清：支持 C盘 / 用户目录 / 全部磁盘 / 按盘勾选四种范围（多盘扫描只比对 ≥4MB 的文件），跳过系统目录，采样哈希（头/中/尾各 16KB）+ 全文件哈希；「快速扫描」开关把全文件哈希换成头/中/尾各 256KB 的强采样，扫描快 5 倍左右，删除时再拿每个副本和保留文件做完整比对；固态盘并行读，机械盘按路径排序后顺序读，避免磁头来回跳；按组显示保留项，删除前重新核对内容；哈希结果按大小和修改时间缓存，文件没变时重复扫描不再读内容
- 微信 / QQ 专清：按目录语义分类聊天视频/图片/语音/接收文件/缓存/日志/朋友圈，按月分组，默认勾选缓存和日志，清理走回收站
- 文件粉碎：随机数据覆盖写入后删除，拒绝系统目录、受保护路径和链接；目录逐个文件粉碎后清空
- 清理历史：每次清理写 `%LOCALAPPDATA%\C盘清理工具\logs\YYYYMMDD_HHMMSS.log`，侧栏「清理历史」查看
- 规则更新：从 `rules_update.json` 里的 https 地址拉取规则，校验后保存到 `%LOCALAPPDATA%\C盘清理工具\rules_remote.json`，下次扫描合并

## 删除安全

所有删除都走同一套检查（[src/safety.rs](src/safety.rs)），宁可跳过不误删：

- 永不清理名单：`\Recovery`、`System Volume Information`、`usmt.ppkg`
- 受保护路径：Windows 目录、Program Files、ProgramData、盘符根、关键系统文件（pagefile 等）
- 用户文档库：文档/桌面/下载/图片/音乐/视频，以及浏览器保存的密码库（Login Data、logins.json 等）
- 重解析点：文件本身和每一级父目录都检查，避免被换成链接
- 外置规则一律按「不可信」处理：目标必须落在临时目录或 `appdata_path_allowlist.json` 的目录模板内
- 重复文件删除前重新计算 BLAKE3 哈希，并核对大小和修改时间；变过的跳过
- 清理项遵守规则里的通配符、排除项和「只清 N 分钟前的文件」
- 删除按句柄进行（`FILE_FLAG_OPEN_REPARSE_POINT`），失败时去掉只读属性重试，仍失败则登记重启后删除
- 大文件和重复副本走回收站，失败不会退回到永久删除
- 隐私清理不碰浏览器密码库；注册表项删除前先导出 `.reg` 备份，导出失败就跳过
- 文件粉碎用系统安全随机数覆盖后删除，界面有二次确认，固态盘上不保证物理层面不可恢复；系统目录、受保护路径和链接一律拒绝
- 微信/QQ 搬家只接受程序自己探测到的数据目录；拷贝后比对文件数和总大小，一致才动原目录；改名与建联接之间中断，下次启动会自动还原
- 关闭微信、浏览器等程序一律放在用户确认清理之后执行，取消确认不会误关软件

## 已知限制

- USB 使用痕迹只统计不清理（改系统设备记录风险高）
- 「电脑搜索记录」没有实现；浏览器/注册表/媒体痕迹已覆盖
- 规则更新保存到 `%LOCALAPPDATA%`，不改动程序内置的 `rules.json`
- 需要系统命令的清理项里，事件日志、搜索索引、注册表残留仍提示「暂未迁移」；DISM 组件精简已支持

## 构建与运行

```bash
cd desktop
cargo build            # 调试版
cargo run              # 启动窗口
cargo test             # 路径安全和删除逻辑的单元测试
cargo build --release  # 发布版
./target/debug/c-drive-cleaner.exe --selftest   # 不开窗口，直接跑一遍后端扫描
```

首次构建会下载 Tauri 依赖，需要几分钟；之后增量编译很快。
程序启动时会检查管理员权限（读 `$MFT` 需要），不是管理员会用 UAC 重新拉起自己。

> 编译特别慢时，通常是杀毒软件在逐个扫描 `target` 目录。把 `desktop/target` 和
> `C:\Users\Administrator\.cargo` 加入杀毒软件的信任目录可以快很多。

## 模块职责

| 功能 | 实现 |
|---|---|
| 清理项统计 | `scan_categories`：解析 `rules.json`，展开环境变量与通配符，按规则遍历 |
| 大文件 | `scan_big`：`mft.rs` 进程内解析 NTFS `$MFT`，多盘并行；非 NTFS 或无权限时退回目录遍历 |
| 重复文件 | `scan_dups`：采样哈希 + 全文件哈希（BLAKE3，rayon 并行），哈希按「大小 + 修改时间」持久缓存 |
| 微信 / QQ | `im.rs`：自适应探测微信真实路径，按目录语义分类，支持一键无痛搬家到其他磁盘（NTFS 联接） |
| 系统深度瘦身 | `system.rs`：Windows 更新下载包、DeliveryOptimization、DISM 组件精简、休眠文件 (hiberfil.sys) 管理 |
| 运行进程检测 | `process.rs`：基于 Toolhelp32 检测微信/浏览器占用，防止文件锁与数据库写冲突 |
| 碎片清理 | `frag.rs`：调用 `defrag.exe` 分析/优化，识别固态盘 |
| 隐私清理 | `privacy.rs`：浏览器 SQLite、最近文件、注册表痕迹 |
| 文件粉碎 | `shred.rs`：随机覆盖后按句柄删除 |
| 清理历史 | `logs.rs`：每次清理写 `%LOCALAPPDATA%\C盘清理工具\logs\YYYYMMDD_HHMMSS.log` |
| 规则更新 | `rules.rs`：https 拉取、校验、保存到 `%LOCALAPPDATA%` |
| 路径安全 | `safety.rs`：永不清理名单、受保护路径、重解析点检查、按句柄删除 |

## 说明

- 规则文件 `rules.json` 在编译时嵌入二进制，改规则后需要重新编译。
- `$MFT` 读取在进程内完成（需管理员权限，非管理员启动时会以 runas 重启）；非 NTFS 卷或读取失败时自动降级为多线程目录枚举。
- 已全面支持：大文件与重复文件右键/双击「定位与打开」、微信一键搬家、WinSxS/DISM 与休眠管理、进程冲突防护等。
